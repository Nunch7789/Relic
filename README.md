# Relic 2.0

An interactive 3D take on the Relic biochip from Cyberpunk 2077: drag to rotate, scroll to dive inside, down to a single neuron, then into the brain.

Relic design by Ben Andrews: https://www.artstation.com/artwork/03qOBK
